# 微传名片 —— 本域名是管理后台，没有任何面向公众的内容页。
# 全站禁止抓取：后台页面（登录、员工、审核、平台管理）被搜索引擎收录
# 只会泄露后台结构，且这些页面都需要登录，收录了也是死链。
#
# 配套措施（三道，缺一不可，见 deploy/baota/nginx-site.live.conf）：
#   1. 本文件            → 让守规矩的爬虫根本不进来
#   2. X-Robots-Tag 头    → 万一被爬到了（外链、聊天软件预览抓取），也标记为不索引
#   3. index.html meta    → 头被某个 location 顶掉时的最后兜底
#
# 若某天要做面向公众的名片展示页 / 官网，必须把那个路径从 Disallow 里放出来，
# 并给它单独的 server 块（或 location）去掉 noindex 头 —— 否则新站永远进不了搜索。
User-agent: *
Disallow: /
