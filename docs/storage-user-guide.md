# 文件存储与分发 · 用户指南

> 面向后台管理员。目标：不看源码、不查搜索引擎，也能判断当前配置、接入云平台、把老文件安全搬过去。
> 设计与迁移细节见 [tenant-storage-design.md](tenant-storage-design.md)。

## 1. 三句话理解这个模块

1. **存储**决定文件（图片、视频、小程序码）真正写在哪里。默认是这台服务器自己的磁盘。
2. **分发（CDN）**决定访客用什么方式更快读到这些文件。默认关闭，关闭时功能完整，只是没有边缘加速。
3. **绑定**决定哪家企业用哪套存储/分发配置。不单独指定时，所有企业共用同一套。

一句话记忆：**存哪 → 怎么加速 → 谁用哪套**。这三件事互相独立，改一件不需要动另外两件。

```
   访客（手机 / 浏览器）
          │  读取文件
          ▼
   ┌──────────────┐   可选，默认关闭
   │  分发 / CDN   │ ← 分发档案（域名、刷新凭据）
   └──────┬───────┘   缓存未命中时回源
          ▼
   ┌──────────────┐   必有
   │  对象存储     │ ← 存储档案（本地磁盘 / 云桶、连接凭据）
   └──────────────┘
          ▲
          │  后台上传
     管理员 / 员工
```

## 2. 默认配置是什么（开箱即用）

| 项目 | 默认值 | 需要做什么 |
|---|---|---|
| 文件存放位置 | 服务器本地磁盘 | 什么都不用做 |
| CDN | 不启用 | 什么都不用做 |
| 存储档案 | 系统自动创建三套内置档案 | 不用创建，不能删除 |
| 分发档案 | 系统自动创建「平台自身 CDN」一行 | 不用创建，不能删除 |
| 企业绑定 | 没有单独绑定，全部走平台自带配置 | 不用设置 |

四套内置档案的职责：

| 内置档案 | 作用 | 限制 |
|---|---|---|
| 平台自身存储 | 平台自己的文件（素材采用、小程序码、访客头像等 `p/` 对象），以及未绑定档案的企业落点 | 可改驱动/连接信息；改完**需重启**；不可删除、不可绑定给企业、不可参与迁移 |
| 平台本地存储 | 云端出故障时的应急退路盘 | 驱动锁本地，目录跟随上传目录；不可删除 |
| 平台本地镜像 | 上传成功后自动留一份副本，只进不出 | 目录跟随镜像目录；不可删除、不可绑定、不可参与迁移 |
| 平台自身 CDN | 平台自己文件的刷新凭据 | 不存域名（域名以访问基址为准）；不可删除、不可绑定；改完**需重启** |

**所以：刚装好就能用。只有磁盘不够、访客访问慢、需要多企业隔离时，才需要往下走接入流程。**

## 3. 完整配置流程（从本地到云）

```
① 看现状 → ② 建存储档案 → ③（可选）建分发档案 → ④ 搬老文件 → ⑤ 切绑定
```

### 第 1 步：先看清楚现在存哪

进入 **平台管理 → 文件存储与分发 → 总览**。顶部三张状态卡直接给出答案：文件存在哪、访客怎么读到、谁在用这套。
这一步不需要改任何东西。

### 第 2 步：需要更大容量时，新建存储档案

1. 按本文第 5 节打开目标云厂商的控制台，**创建存储桶**，并把桶设为**公共读**（当前系统只支持公开读桶）。
2. 在同厂商的密钥管理页面创建 **AccessKey / SecretKey**，页面关闭后通常不再显示，先复制备用。
3. 回到 **存储档案 → 新建存储档案**：选驱动，按弹窗里的官方链接和字段说明填写。
4. 点 **自检**。通过才说明系统真的能读写这个桶；不通过时按报错检查端点、桶名、密钥和桶权限。
5. 此时**不会影响任何现有文件**——档案只是建好了，还没有被任何企业使用。

> 平台自己的文件要上云：编辑内置的「平台自身存储」那一行，改完**必须重启服务**。
> 普通企业档案不会立即被使用，要等第 5 步切换绑定。

### 第 3 步（可选）：让访客访问更快

1. 在云厂商开通 CDN，接入你的桶，配置好加速域名并完成 CNAME 解析。
2. 回到 **分发档案 → 新建分发档案**：选厂商，填公开域名和刷新凭据。
3. 点 **自检** 验证刷新接口可用。
4. 这一步只改变访客侧的 URL，不改变文件存在哪。

平台自己的文件用内置的「平台自身 CDN」那一行；它不填域名，域名以存储档案的**访问基址**为准。改完**需重启**。

### 第 4 步：把老文件搬到新桶

**切换之前必须先搬，否则访客会拿到裂图。**

1. **迁移任务 → 创建任务**：选范围（全平台或某家企业）、源档案、目标档案。
2. 先勾 **试运行**，看看对象数量对不对。
3. 取消试运行，启动任务。视频按流式搬运，不会整段进内存。
4. 失败对象会进失败清单，可导出 CSV、重试失败；只有**零失败**才建议切换。

迁移**只复制不删除**，源桶原样保留，随时可以回滚。

### 第 5 步：切换生效

**绑定关系 → 全局默认**：选择新存储档案和分发档案，保存。保存前系统会核对新档案是否包含旧档案里的全部对象，缺一个就拒绝切换；**下一个请求立即生效，不需要重启**。

- 切错了：用「回滚到上一套」。回滚只换绑定，不搬对象；切换后新上传的文件仍在新桶，属预期。
- 只有确认目标本来就是新桶、无需搬迁时，才勾选「强制切换」跳过核对。
- 可以给某家企业单独在「企业覆盖」里指定；删掉该行即恢复继承全局。

> 例外：修改的是**平台自身存储**或**平台自身 CDN** 这类启动期配置时，保存后仍需重启服务。

## 4. 每个菜单和页签是干什么的

### 侧栏菜单（鼠标悬停可看一句话说明）

| 菜单 | 什么时候用 |
|---|---|
| **文件存储与分发** | 图片视频存哪、怎么加速访问。档案、绑定、迁移、总览都在里面 |
| **CDN 刷新** | 日常替换同名文件时系统会自动刷新；这里只在云控制台直接换了文件、或要立刻让边缘失效时手动使用 |
| **备份与恢复** | 检查数据库、上传文件、密钥三部分备份是否齐全和多新鲜，可临时补一份 |
| **系统设置** | 品牌名、上传大小、有效期等运行参数。存储连接和 CDN 凭据已搬进档案模块 |

### 「文件存储与分发」内的页签

| 页签 | 管什么 |
|---|---|
| **总览** | 一页看清架构、当前状态、配置流程和所有云平台官方入口。第一次进来先看这里 |
| **存储档案** | 管「文件存哪」。一套档案写一次连接信息，多家企业共用 |
| **分发档案** | 管「访客怎么更快读到」。CDN 与存储独立，同一个桶可以配多套加速 |
| **绑定关系** | 管「谁用哪套」。不单独指定就用全局默认，改完立即生效 |
| **迁移任务** | 管「老文件怎么搬到新桶」。只复制不删除，零失败后才建议切换 |
| **平台自身存储（启动配置）** | 平台自己那份文件的目录、备份开关、访问基址。通常不用改，改完需重启 |

## 5. 配置项说明

### 5.1 存储档案

页面每个输入框旁的 **?** 会显示四段说明：功能、值从哪来、规则限制、容易踩的坑。

| 配置项 | 功能 | 值从哪来 / 填法 |
|---|---|---|
| 档案名 | 给自己看的标识 | 随便起，方便在绑定和迁移时认出来 |
| 存储方式（驱动） | 决定文件写进哪 | 本地磁盘（默认）/ MinIO / 阿里云 OSS / S3 兼容 |
| 服务地址（Endpoint） | 厂商 API 入口 | 控制台桶详情里的「访问域名 / S3 端点」；只填主机名，**不带 `https://`** |
| 存储桶名（Bucket） | 云端放文件的文件夹 | 先在控制台创建桶，通常是全局唯一且不能改名 |
| 地域（Region） | 桶所在区域 | 创建桶时选的地域代码；S3 兼容可留空 |
| 访问基址 | 上传成功后返回的 URL 前缀 | 你的 CDN 域名或桶公开域名，如 `https://cdn.example.com/uploads`；必须是完整 https 地址 |
| 主机头（高级） | 路径风格 / 虚拟主机风格 | 一般留空；选错会签名失败。不确定就留空并点自检 |
| 使用 HTTPS | 连接厂商 API 是否加密 | 默认开启；阿里云 OSS 强制 https |
| 公开读桶 | 访客免签名直接读 | 当前固定开启；还需在云控制台把桶设为公共读 |
| AccessKey | 厂商 API 的「用户名」 | 用弹窗上方的密钥管理链接直达创建页面 |
| SecretKey | 厂商 API 的「密码」 | 与 AK 同一页面一次性显示；保存后只回显掩码 |
| 本地根目录 | 本地模式写到哪 | 普通档案可自由填；内置档案的目录继承自启动配置，改那里并重启 |

### 5.2 分发档案

| 配置项 | 功能 | 值从哪来 / 填法 |
|---|---|---|
| 档案名 | 给自己看的标识 | 随便起 |
| CDN 厂商 | 用哪家的加速和刷新 | 选「不启用 CDN」表示不刷新、不需要凭据 |
| 公开域名 | 访客访问文件的域名 | 在厂商控制台接入域名并做 CNAME 后得到；必须是 https 地址 |
| 路径前缀 | 只加速某个目录时填 | 一般留空，表示整站都走这套 CDN |
| 刷新接口地址 | 提交刷新请求的地址 | 留空用系统内置默认值 |
| 资源标识 | 要刷新哪个加速区域 | 仅 Cloudflare（Zone ID）和 CloudFront（Distribution ID）需要填 |
| AccessKey / Token | 调用刷新接口的账号标识 | Cloudflare 不用这一项 |
| SecretKey / API Token | 调用刷新接口的密钥 | Cloudflare 把 API Token 填这里 |

### 5.3 其他

| 位置 | 配置项 | 说明 |
|---|---|---|
| 绑定关系 | 全局默认 | 不选「强制切换」时，系统会核对目标是否包含全部旧对象；缺对象就拒绝切换 |
| 绑定关系 | 企业覆盖 | 单家企业单独指定；「恢复继承」删掉该行回到全局默认 |
| 绑定关系 | 强制切换 | 逃生开关。只在确认目标本就是新桶、无需搬迁时才勾 |
| 迁移任务 | 试运行 | 只统计不复制，用来核对对象数量 |
| 迁移任务 | 成功后自动切换绑定 | 零失败才允许；需要提前勾上 |
| 平台自身存储 | 本地上传目录 / 本地镜像目录 | 内置档案目录的唯一真值源；改完需重启，两个目录不能互相包含 |
| 平台自身存储 | 本地镜像开关 | 文件上传成功后是否自动留本地副本，默认开 |
| 系统设置 | 存储配额 / 上传大小 / 链接有效期 | 只留运行参数；连接信息和 CDN 凭据不在这一页 |

各家凭据填法：

- **阿里云 CDN / 腾讯云 CDN / 七牛云 CDN**：AK / SK 填到 AccessKey / SecretKey；资源标识留空，系统按 URL 域名自动定位加速域名。

## 7. 常见问题

**Q：我只想先跑起来，必须接云吗？**
不用。默认本地磁盘 + 不启用 CDN 就是完整可用配置，不需要任何云账号。

**Q：自检通过但还是裂图？**
检查三处：桶是否真的设成公共读；「访问基址」是否是正确的对外域名；如果开了 CDN，域名是否正确解析并已刷新。

**Q：切到新桶后老图片不见了？**
说明切换前没搬完。老文件还在源桶（迁移只复制不删除）。先用「迁移任务」补搬，或用「回滚到上一套」退回。

**Q：为什么改了配置没生效？**
看改动位置：普通企业档案和绑定是即时生效；平台自身存储、平台自身 CDN、上传目录、镜像目录这类启动参数需要重启服务。页面在「平台自身存储」页签会列出需重启的项。

**Q：能把内置档案删掉换成自己的吗？**
不能。三套存储内置档案和一套分发内置档案是系统正常运行的骨架。要接云就新建档案并切换绑定，或改「平台自身存储」那一行的连接信息。

**Q：接了云还能用本地备份吗？**
可以。本地镜像开关默认开启，文件上传到云端后系统会自动在本地镜像目录留一份副本；这份副本只做备份，不参与读取和绑定。
